# POE Part 3 - POEMutshidzi

Student: Mutshidzi Netshitavhadulu
Module: PROG5121 / POE Part 3

## Description
QuickChat messaging application with login, registration, message sending, storing, and JSON storage.

## Features
- User registration and login with validation
- Send, store, and search messages
- Message IDs, hashes, and flags
- JUnit tests for Login and StoredMessages

## How to Run
1. Open project in NetBeans
2. Run Main class
3. Follow menu to register, login and send messages
